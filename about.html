ABOUT NOTE GUESS

A music break
with a point.

NoteGuess is a small, free Guess the Song Game for quick daily play. It was made for people who enjoy recognizing melodies without needing an account, app, or commercial music stream.

How the game works

The quiz uses short browser-generated arrangements of public-domain source melodies. Each daily session has five rounds, optional hints, and a local streak. The current implementation uses the Web Audio API, so nothing is downloaded or uploaded when a player hears a clip.

Who makes NoteGuess?

NoteGuess is created and maintained by Joan Jiao. The source project is available on GitHub for transparency, issue reporting, and technical feedback.
